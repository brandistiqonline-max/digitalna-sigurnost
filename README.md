# Digitalna sigurnost — početna web-verzija

Staticka, responzivna web-stranica za Netlify.

## Sadržaj
- Početna, građani, poduzetnici, vodiči, alati, knjiga, usluge, o projektu, kontakt, privatnost
- 12 zasebnih edukativnih vodiča
- Lokalna procjena probne lozinke (ne šalje podatke)
- Edukativni phishing kviz
- Kontrolna lista za osnovnu samoprocjenu poduzetnika
- Ugrađeni promotivni MP4 video
- Promotivni MP4 video i naslovnica knjige
- Osnovna Netlify sigurnosna zaglavlja, robots.txt i sitemap.xml

## Lokalni pregled
Otvori `index.html` u pregledniku ili pokreni lokalni statički poslužitelj iz ove mape.

## Objavljivanje na Netlify
1. Raspakiraj ZIP.
2. Prenesi mapu u GitHub repozitorij.
3. U Netlifyju odaberi Add new site → Import an existing project.
4. Odaberi GitHub repozitorij.
5. Build command ostavi praznim; Publish directory postavi na `.`.
6. Nakon prvog deploya dodaj domenu `digitalna-sigurnost.com.hr` u Domain management i postavi DNS zapise koje Netlify prikaže.

## Prije javne objave obavezno
- Unijeti stvarne podatke nositelja projekta i kontakt adresu.
- Pregledati pravne tekstove i politiku privatnosti prema stvarnoj obradi podataka.
- Odlučiti hoće li se PDF/EPUB nuditi besplatno ili uz plaćanje; trenutno su datoteke dostupne za izravno preuzimanje.
- Povezati stvarni kontaktni obrazac i potvrđenu kontakt adresu.\n- Definirati cijenu, uvjete kupnje i sigurnu isporuku prije aktivacije prodaje knjige.\n- Ako se doda analitika, newsletter, vanjski video player ili plaćanje, ažurirati privatnost i privole.
- Provjeriti sve vanjske poveznice i sadržaje prije objave.
- Postaviti DNS i potvrditi HTTPS.
